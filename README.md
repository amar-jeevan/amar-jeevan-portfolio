## About

## Featured Project
### Cryogenic Cable Simulator
A Python-based simulation framework developed to analyze heat conduction in cryogenic cable systems with temperature-dependent material properties, nonlinear steady-state behavior, and limited cooling power.

Key aspects:
- Fourier heat conduction modeling
- Temperature-dependent thermal conductivity
- Nonlinear numerical solution methods
- Multi-segment cable architecture
- Engineering visualization and analysis workflows
