Featured Engineering Project

Cryogenic Cable Simulator

Thermal Modeling | Python | Numerical Methods

A physics-based simulation framework developed to analyze heat conduction in cryogenic cable systems under realistic cooling power constraints.

Project Context

This project was developed in the context of my Master’s thesis at Forschungszentrum Jülich. The engineering problem was to evaluate thermal behavior in cryogenic cable systems where material properties vary strongly with temperature and the available cooling power is limited.

Engineering Objective

The goal was to build a reusable simulation framework capable of estimating temperature profiles, thermal loads, and realistic operating points in multi-segment cryogenic cable architectures. The model needed to be flexible enough for parameter studies and technically structured enough to support future validation work.

What I Implemented

Physics-Based Modeling

Implemented Fourier heat conduction with temperature-dependent material behavior for engineering-relevant thermal analysis.

Numerical Solution Methods

Built nonlinear steady-state solution workflows using numerical integration and iterative methods.

System-Level Architecture

Modeled multi-segment cable systems with cascaded thermal boundaries and cooling constraints.

Technical Stack

Python NumPy SciPy Matplotlib Jupyter Voila Scientific Computing Thermal Modeling

Key Outputs

  • Nonlinear temperature profiles across cryogenic cable segments
  • Steady-state operating point analysis under cooling power limits
  • Comparison of conduction behavior and available cooling capacity
  • Structured simulation workflow for parameter studies and future validation

Engineering Relevance

The project demonstrates how physical models can be translated into robust computational tools for engineering analysis. It combines thermal systems understanding, numerical methods, and practical software implementation in a way that is relevant for simulation, R&D, and design-support roles.
